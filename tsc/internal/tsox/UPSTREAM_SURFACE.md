# Upstream dependency surface

Every import of an internal upstream symbol by TSOX code gets an entry here:
the package/symbol, the fact we extract from it, and why. An internal import
without an entry is a defect. This file is the checklist every version-bump
review diffs against.

| Package / symbol | What we extract | Why |
|---|---|---|
| `internal/core` — `Version()` | The embedded TypeScript version string | Proof-of-wiring smoke test (`tsc/tsox.Marker`) |
| `internal/ast` — `Node`, `SourceFile`, `Symbol`, `ModifierList`, `Diagnostic`; `SourceFile.AsNode`; `Node.ForEachChild`, `Node.Text`, `Node.Name`, `Node.Pos`, `Node.End`, `Node.Parent`; `Diagnostic.File`, `Diagnostic.Pos`, `Diagnostic.String`, `Diagnostic.Code`; `Kind.String`; `GetSourceFileOfNode`, `IsIdentifier`, `IsVariableDeclaration`, `IsVarConst`, `IsStatement`, `IsAssignmentOperator`; `Symbol.Name`, `Symbol.Declarations`, `Symbol.ValueDeclaration`; the guarded `As*` accessors and fields for source files, blocks, interface/type-alias/type-literal/property-signature declarations, variable/parameter/function declarations, expression/return/if/while/for/for-of statements, identifiers/literals, object/array literals, property assignments, binary/prefix/postfix/call/property-access/element-access/template/arrow/parenthesized expressions; the corresponding `Kind*` constants; `NodeFlagsBlockScoped`, `NodeFlagsLet`, `NodeFlagsConst`; `SymbolFlagsValue` | Checked syntax shape, named-shape identity and declaration-order fields, lexical symbol identity and declaration provenance, declaration mutability and write targets, literal/operator data, source byte ranges and parent statements, node-kind names, and TypeScript diagnostic file/position/message/code data | Build the closed graph allow-list, discover call and read-only binding-use mutation spans, admit calls only to source-owned functions, fence anonymous/recursive/cross-declaration shapes and array methods, name fenced constructs, and preserve binding and shape identity without retaining AST or symbol pointers; phase-one tests also pin traversal and composite-resolution facts |
| `internal/bundled` — `WrapFS`, `LibPath` | The compiler's embedded default-library filesystem | Construct checked in-memory programs without host filesystem dependencies |
| `internal/checker` — `Checker`, `Type`, `ContextFlagsNone`, `SignatureKindCall`, `TypeFlagsNumberLike`, `TypeFlagsStringLike`, `TypeFlagsBooleanLike`, `TypeFlagsVoidLike`, `TypeFlagsObject`; `GetTypeAtLocation`, `GetContextualType`, `GetContextualTypeForArgumentAtIndex`, `GetSymbolAtLocation`, `GetGlobalSymbol`, `GetSignaturesOfType`, `GetTypeOfSymbol`, `GetReturnTypeOfSignature`, `GetPropertyOfType`, `IsArrayType`, `GetElementTypeOfArrayType`, `TypeToString`; `Type.Flags`, `Type.Symbol`, `Type.Alias`; `TypeAlias.Symbol`; `Signature.Parameters` | Checked primitive/function/object/recursive-array types, contextual literal and call-parameter types, declaration and property identities, resolved lexical bindings, the real global `console`, and callable parameter/result shapes | Make operations, calls, named shapes, fields, literals, indexed access, `for-of`, and mutation compatibility semantic before they cross the fork seam; enforce the named-shape and array-method fences; and never confuse a shadowed `console` binding with the supported builtin |
| `internal/compiler` — `NewCompilerHost`, `NewProgram`, `ProgramOptions`; `Program.BindSourceFiles`, `GetSourceFile`, `GetSourceFiles`, `GetSyntacticDiagnostics`, `GetSemanticDiagnostics`, `GetTypeChecker` | A bound, syntactically and semantically checked single-threaded program plus its one checker | Use the compile-verified embedding recipe and keep every type/symbol identity in one checker domain |
| `internal/core` — `CompilerOptions`, `TSTrue`, `ModuleDetectionKindForce`, `UTF16Offset` | Strict/single-threaded/module-scoped configuration and diagnostic column units | Keep one checker identity domain, prevent bundled DOM script globals from colliding with program bindings, and report TypeScript-compatible source columns |
| `internal/jsnum` — `FromString` | The exact IEEE-754 value of a scanner-normalized TypeScript numeric literal | Reuse the compiler's JavaScript numeric parser instead of inventing literal conversion |
| `internal/scanner` — `GetTokenPosOfNode`, `GetTextOfNode`, `GetECMALineAndUTF16CharacterOfPosition` | A construct's trivia-free token start, exact source text, and zero-based line/UTF-16 column | Fence diagnostics name the source position users see, and mutation sites retain exact text coordinates and identifier names |
| `internal/tsoptions` — `NewParsedCommandLine` | Compiler configuration for an explicit root file | Drive one source file without inventing tsconfig behavior |
| `internal/tspath` — `ComparePathsOptions` | Case-sensitive path normalization rooted at the in-memory source directory | Keep program and virtual-filesystem path identity consistent |
| `internal/vfs/vfstest` — `FromMap` | In-memory source files | Extractor input stays deterministic and does not touch the host filesystem |
| `internal/parser` — `ParseSourceFile`; `internal/ast` — `SourceFileParseOptions`, `SourceFile.FileName`, import-declaration/import-clause/named-import/import-specifier guarded accessors and fields, export/import-equals/dynamic-import kind constants, `Symbol.Flags`, `SymbolFlagsAlias`; `internal/core` — `ScriptKindTS`; `internal/tspath` — `Path` | Explicit relative dependency specifiers, type-only import edges, original module locations, and import alias classification | Snapshot only the bounded module graph before constructing a checker; diagnose unsupported module forms without resolving package graphs; preserve dependency identity and positions |
| `internal/checker` — `GetAliasedSymbol` | The original checker symbol behind a named import alias | Imported reads, writes reached through source helpers, and named shapes retain their actual shared binding identity instead of acquiring copied import-local storage |
| `internal/core` — `ModuleKindESNext`, `ModuleResolutionKindBundler`; `CompilerOptions.Module`, `ModuleResolution`, `AllowImportingTsExtensions`, `NoEmit`, `VerbatimModuleSyntax` | An explicit-.ts ESM checker domain with required declaration-level type-only imports | Match Node's stripped TypeScript import meanings inside the bounded module contract; share checked sources with entry-only mutation extraction |
| `internal/checker` — `GetSymbolsInScope`, `GetNonNullableType`, `Type.Types`, `TypeFlagsUnion`, `TypeFlagsUndefined`, `TypeFlagsNull`; `internal/ast` — `GetCombinedModifierFlags`, `ModifierFlagsReadonly`, `SymbolFlagsProperty`, `Node.Expression`, `Node.Initializer` | Visible initialized replacement donors, declared optionality, writable data-property prefixes, and stable receiver syntax | Generate bounded receiver writes inside index/argument evaluation without selecting an inaccessible donor, writing readonly data, or re-evaluating an effectful receiver path; preserve the original binding-ID surface |
| `internal/checker` — `GetPromisedTypeOfPromise` | The fulfillment type of the explicitly annotated intrinsic Promise at the async host boundary | Extract checked string host results and named response shapes without treating arbitrary Promise/thenable values as synchronous graph values |
| `internal/ast` — guarded `AsAwaitExpression`, `AsTryStatement`, `AsCatchClause`, `AsThrowStatement`, `AsTypeReferenceNode` and their expression, try/catch/finally block, binding and type-argument fields; corresponding `Kind*` constants and `KindDeclareKeyword` | One positioned direct await, synchronous abrupt completion/catch/finally regions, and the selected ambient host declaration's syntax | Admit the separate bounded async entrypoint, retain source-order effects and diagnostics, and prove the awaited call targets the selected ambient symbol rather than a same-spelling implementation |
